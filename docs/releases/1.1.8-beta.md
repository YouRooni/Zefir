- automation: commands for Tasker, MacroDroid, adb and scripts, plugin for Tasker and MacroDroid, off by default (see docs/AUTOMATION.md)
- Xray JSON balancers open as folders with an auto server and their configs
- own servers: AnyTLS, Mieru, SSH, VLESS over XHTTP; protocol picker grouped by type
- home screen: dividers, separate session time and session traffic widgets, widgets reorder by long press
- subscriptions: compact cards with update time and traffic left, reorder by long press, list opens on the active one
- servers hidden by filter can be shown below the list
- option to turn off animations
- desktop: right click opens the same menu as long press on Android
- Windows and Linux: title bar follows the current screen color
- Linux: TUN mode, tray, system accent color, own title bar, data moved to $XDG_DATA_HOME/zefir
- Android: long press on an app in split tunneling opens its system info
- quick subscription switching reconnects once instead of on every tap
- subscriptions larger than 32 MB are rejected instead of running out of memory
- ping: replies slower than 5 s count as no reply
- fixes for drag and drop, crash when dropping a subscription

Beta release. Windows binaries are not code-signed.
