# Security

Send vulnerability reports privately to [Telegram @YouRooni](https://t.me/YouRooni) or [studio.rooni@gmail.com](mailto:studio.rooni@gmail.com). Include the affected version and platform, the impact, and steps or a minimal example that reproduces it. Do not open a public issue containing an exploit or private credentials.

Security fixes target the latest release, including the latest beta. Older versions do not have a separate maintenance branch. Reports are handled on a best-effort basis; there is no guaranteed response time or paid bounty program.
